# NERDS v0.2.1 — Revision C: Worldwide Waypoint Discovery & Clean Workspace

**Date:** 14 October 2026
**Status:** Approved amendment to the v0.2.1 scope.
**Precedence:** Revision C supersedes conflicting requirements in Revision B and prior versions. All unrelated Revision B acceptance findings, global UI rules and application requirements remain in force.

## C1 — Remove the starter-city demonstration

- Completely remove the hardcoded **15 starter cities**, the corresponding selection interface and all demonstration waypoint seeding.
- Every new project starts with **ZERO waypoints** and no preassigned route.
- A separate, explicitly launched demonstration video or example project may be created later; it must never populate a new production project.
- Alphabetise appropriate lookup and dropdown results. **Do not** alphabetise the user's ordered waypoint list.

## C2 — Three methods to add waypoints

1. **CITY LOOKUP:** Search worldwide for cities, towns, villages and recognised named places. Select the result and add an editable waypoint.
2. **PLACE MAP PIN:** Click anywhere on the globe to add a named waypoint, including anchorages and uninhabited locations.
3. **MANUAL COORDINATES:** Enter a waypoint name, latitude and longitude.

All three methods must support edit, delete, reorder, map synchronisation, project saving and reliable reopening. Waypoint identifiers must remain stable independently of list position. No hardcoded city-list or mandatory water-access step is permitted.

## C3 — Worldwide offline-first place search

- **GeoNames** is the proposed initial local worldwide gazetteer, subject to licence verification, proper attribution and suitability. Bundle or locally provision a useful worldwide indexed location database.
- Provide responsive local place-name search **without internet connectivity**.
- When connected, offer online fallback for missing/ambiguous locations. Evaluate OpenStreetMap-derived geocoding for supplementary details, subject to service-use restrictions and licences.
- Disambiguate matches using country, administrative region and relevant coordinates. Preserve alternate names or spellings where available.
- Store source identifiers, source provenance, resolution method and user overrides. Document database updating and coverage.
- Installer/data size is **not** an optimisation constraint: **MAKE IT WORK. MAKE IT FAST. MAKE IT AWESOME. IT CAN BE HUGE.**

## C4 — Coordinate anchors and route plotting

- For cities, use City Hall/municipal-centre coordinates when reliably resolvable; otherwise use the documented city-centre coordinates.
- For manual coordinates or map pins, preserve the exact user-provided location.
- **PLOT ROUTE** must operate without requiring manually assigned harbour/water-access points. It may generate approximate connector geometry from city anchors to offshore water routing, with connectors clearly distinguished from navigable legs.
- Coarse routing is for preliminary global planning only. High-resolution harbour approaches, canals, depth, clearance and chart-constrained validation remain later engineering phases. Do not label unvalidated geometry navigationally verified.

## C5 — Acceptance criteria

- **AF-003:** A new project presents zero waypoints and no list of starter cities.
- **AF-004:** Offline lookup resolves representative places across continents; search results are disambiguated and selectable; connected fallback is available.
- Create a waypoint by each of the three methods; modify and reorder, then save and reopen the project with no data loss.
- Preserve existing verified drag-to-reorder and SAVE PROJECT behaviour.
- Maintain Revision B requirements for vessel preference persistence, 6 kn reference and 10 kn powered target, side-by-side estimates, offshore routing, 24-hour clocks with explicit time zones, universal DONE/CANCEL/X dialog rules, map overlays and the 19-item acceptance register.

## System boundary

NERDS is a standalone navigation/geographic application. **4nR-SURVEYOR** is a separate research application with independent versioning, storage and configuration; any map hints pass through an optional documented interface.
