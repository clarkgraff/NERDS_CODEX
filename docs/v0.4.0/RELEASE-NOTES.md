# NERDS 0.4.0 development test

This build uses a separate Windows product identity (NERDS Development Test) and default data folder (%APPDATA%/NERDS-Development-Test). It does not migrate the production installation or its preferences. Use copies of existing projects when testing; explicitly saving an opened project writes that file.

Operational: map-pin and coordinate waypoint entry, name search, reorder/edit, geographic route plotting and mapped-waterway refinement, WGS84 distance and nominal times, original-course comparison, USER PATH/course persistence, offline geographic-cache inspection/preparation, direct USER PATH measurement, geographic hover and coordinate-based right-click discovery.

Offline cartography: Natural Earth 1:10 million coastlines plus added rivers/lakes/regional boundaries/place labels, existing roads and national boundaries, zoom thresholds, label clustering and selectable reference layers. No satellite imagery. Palette follows the approved ocean/land/border/road colours. Source licenses and hashes: assets/layers/v040-sources.json. Coastline source resolution remains 1:10 million; this is not harbour-scale chart detail.

Known limitations: no elevation-derived hypsometric colouring or hillshading; adjustable globe lighting is clearly labelled separately. Regional/place datasets are generalised. Hover currently identifies populated-place labels or coordinates, not every river/road feature. Right-click discovery provides selected coordinates and offline-search guidance; CRONKITE is proposed only. Existing transport context commands remain. No new waypoint-specific context actions were added. Detailed manual course editing, full multimodal transport tracking and Stage 3 remain outside this test increment.

The 3 GB expanded GeoNames discovery index remains preserved in the development checkout but is excluded from this test MSI. The installed seed gazetteer contains 236,427 places. Worldwide routing coverage remains incomplete; live provider acquisition and polar-cap topology remain unresolved. No unsupported connection is converted to PASS. Coarse direct-path measurements are explicitly not water routes.

Tests and evidence: end-to-end.json and ui-smoke.json record packaged execution in isolated user-data directories. Automated window testing uses 3840x2160 logical pixels; physical screenshots reflect Windows display scaling. The bundled geography processor runs without external development Python. This build is unsigned and is a development test, not a production navigation release.

Separate accounting check confirms 9.674967225199428 NM at 6 knots equals the stored nominal durations. Original v0.3.0 registry entry remains; production config.json and nerds.sqlite SHA-256 values are unchanged. Initial unit run: 74 passed, two reference-comparison configuration failures. Configuring NERDS_PREPARATION_PYTHON and rerunning the affected suites: six passed. Final affected UI/model suites: 17 passed. Routing-memory suite: three passed. No geographic coverage reclassification is claimed.

Reproduction: npm run package; NERDS_TEST_EXE points to the installed NERDS Development Test.exe, NODE_PATH supplies the development Playwright test harness, then node test/v040-ui.cjs and node test/canonical-desktop.cjs. These harness dependencies are not application requirements. Installation uses msiexec /i with a separate INSTALLDIR and a silent log. See delivery.json for exact installer identity and hash.
